# Cambridge English Skills Test (General) - Test Specification & Coaching Master Guide

## 1. Test Architecture & Structure Overview

The Cambridge English Skills Test (General) is an online, multi-level adaptive assessment reporting across the Common European Framework of Reference (CEFR) from **Pre-A1/A1 to C1**. 

* **Delivery Engine**: Cambridge Metrica Test Delivery (`metritests.com`).
* **Adaptive Mechanism (Reading & Listening)**: The test adapts to the candidate's real-time performance. Difficulty increases or decreases dynamically to pinpoint CEFR ability with ~0.94 reliability. Once an item or section screen is submitted, candidates **cannot backtrack**.
* **Writing**: Timed 45-minute module with two tasks, evaluated by the ALTA automated language assessment engine (machine learning model developed with Cambridge University) against CEFR rubrics.

## 2. Module Specifications

### A. Reading Component (33 Scored Items in Sample; Adaptive in Live Exam)
| Task Type | Focus & Sub-skill | Format | CEFR Target |
| :--- | :--- | :--- | :--- |
| **Task 1: Notices & Signs** | Reading for transactional gist/detail | 1 short notice + 3-option MC | A2–B1 |
| **Task 2: Sentence Gap-Fill** | Lexico-grammatical precision in single sentence | 1 gapped sentence + 3-4 options | A2–B1 |
| **Task 3: Open Gap-Fill** | Grammatical syntax & function words in running text | 1 passage with 5 gaps (Candidates type ONE word only) | B1–B2 |
| **Task 4: Multiple-Choice Gap-Fill** | Vocabulary, collocations, phrasal verbs, idioms | 1 passage with 5 gaps + dropdown/word choices | B1–B2 |
| **Task 5: Long Text Multiple Choice** | Detailed comprehension, attitude, opinion, inference | 1 extended text + 5 MC questions | B2–C1 |
| **Task 6: Short Article Multiple Choice** | Gist and specific information in opinion/feature pieces | 1 medium text + 2 MC questions | B1–B2 |
| **Task 7: Missing Sentence Insertion** | Cohesion, discourse markers, reference chains | 1 text with 5 gaps + 8 sentence choices (3 distractors) | B2–C1 |
| **Task 8: Missing Paragraph Insertion** | Macro text structure and thematic progression | 1 text with 5 gaps + 6 paragraph choices (1 distractor) | C1 |
| **Task 9: Multiple Text Matching** | Cross-text comparison, contrasting perspectives | 4 short texts on same topic + 4 questions matching to A, B, C, D | B2–C1 |

### B. Listening Component (19 Scored Items in Sample; Adaptive in Live Exam)
*All audio tracks play twice automatically. 10–45 seconds pre-listening reading time is provided.*
| Task Type | Focus & Sub-skill | Format | CEFR Target |
| :--- | :--- | :--- | :--- |
| **Task 1: Picture Multiple Choice** | Identifying concrete details & visual cues | 1 short dialogue + 3 picture options | A1–A2 |
| **Task 2: Short Dialogue MC** | Inferring speaker intent, agreement, gist | 1 short dialogue + 3 text options | A2–B1 |
| **Task 3: Extended Audio MC** | Following an argument, identifying factual details | 1 longer conversation/interview + 5 MC questions | B1–B2 |
| **Task 4: Two-Question MC** | Detailed comprehension in media/debates | 1 monologue/dialogue + 2 MC questions | B2 |
| **Task 5: Multiple Matching** | Extracting main points across multiple speakers | 5 short monologues on shared theme + 8 option statements | B2–C1 |
| **Task 6: Sentence Completion** | Listening for exact lexical items in monologues | 1 lecture/talk + 5 gapped sentences (write 1–3 words) | B2–C1 |

### C. Writing Component (45 Minutes Total)
| Task | Genre & Audience | Prompt Constraints | Evaluated Dimensions |
| :--- | :--- | :--- | :--- |
| **Part 1** (~15 min) | **Informal Email** to a peer/friend | Write **≥50 words** covering 3 prompt bullet points | • Communicative Achievement (tone, conventions)<br>• Organisation (coherence, basic connectors)<br>• Language (range & control of everyday vocabulary/grammar) |
| **Part 2** (~30 min) | **Public Web Contribution** (Forum/Website post) | Write **≥180 words** analyzing causes, impacts, and solutions for a local community issue | • Communicative Achievement (holding reader attention, complex ideas)<br>• Organisation (logical paragraphs, discourse signposting)<br>• Language (complex syntax, topical lexis, collocations) |

## 3. Psychometric & Pedagogical Construct Analysis

### Key Traps & Cognitive Demands
1. **The "Word-Spotting" Distractor (Reading & Listening)**:
   * Cambridge deliberately places exact words from the text into incorrect options. The correct answer is virtually always a **lexical or syntactic paraphrase**, not a verbatim repeat.
2. **Audio "Distractor Reversal" (Listening)**:
   * Speakers regularly mention Option A, then use a discourse contrast marker (*"I was leaning towards that initially, but then I realized..."*) to switch to the correct Option B.
3. **Open Cloze Constraints (Reading Task 3)**:
   * Gaps *never* take content words (nouns, main verbs, descriptive adjectives). They are strictly structural/grammatical: auxiliary verbs (*had, been*), relative pronouns (*which, where*), prepositions (*at, in*), determiners (*each, every*), or connectors (*although, despite*).
4. **Writing AI Scoring Engine Mechanics**:
   * Evaluated by ALTA ML algorithms. High-scoring scripts demonstrate:
     - Lexical richness (synonyms, collocations) without unnatural vocabulary stuffing.
     - Syntactic variety (mix of compound, complex, conditional, and passive clauses).
     - Full prompt coverage (addressing all bullet points thoroughly).
